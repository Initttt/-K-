## 已验证的行为

1. **设备管理和保存**：新账户空状态；添加完整设备；刷新仍存在；修改名称与购买价；取消删除后保留；确认删除移除设备和关联估值；再刷新保持删除结果。
2. **估值和汇总**：8000 元购入、5000–6000 元区间产生中值 5500、变化 −2500；加入 2000 元但无估值的设备后，估值和变化不变；编辑购入价后按新口径计算。零买入价与零估值合法，变化率不除零，无 NaN 或 Infinity。
3. **历史和刷新**：没有估值显示暂无；单个参考快照显示一个点；超过七天提示复核；重复刷新手动或固定模拟行情不改变原 JSON、价格、日期或记录数量。
4. **演示隔离**：五件初始样例、四件估值，模拟参考总值 35,600 元；显卡显示估值上升，曲线六个点；切回个人空间仍为空。类别筛选只显示对应设备。
5. **备份与恢复**：下载 JSON 后检查设备数量；删除后导入备份，显示记录预览；明确确认替换后恢复设备和估值。
6. **地区和币种**：人民币与美元账户相互独立；切换后刷新保留选定市场；切回后原有设备仍在。不进行汇率换算。
7. **输入与故障**：必要字段错误、未来购买日期拒绝、显卡不显示电池字段；损坏本地数据时保留原文、显示错误且禁止新增；点击已选空间也不会抹去错误。
8. **AI 未配置**：状态真实返回未配置，提取按钮禁用，仍能转到手动录入并完成新增。默认无任何付费调用。
9. **AI 成功预填**：浏览器测试拦截接口并返回明确标记的测试数据；验证只填明确信息，品牌与不完整日期仍为空，提交中带当前币种；用户补全并确认前不会写入账本。这只验证前端集成，**不代表真实模型服务已验证**。
10. **手机布局**：实际操作添加、查看详情、填写零估值、重载、切换演示；主页面与详情弹窗无横向溢出。截图经过视觉检查。

单元测试额外覆盖：当天购买按一天、未来日期不计算、中值、最新快照排序、跨市场拒绝、稳定模拟匹配、非法备份、模拟与个人数据拒绝混入、未经验证的真实来源拒绝导入、存储权限/容量错误、AI 缺配置/拒绝/限流/超时/错误输出/请求体限制/同源校验/币种不匹配。
